# Process Metrics

| Date | Project | Gate | Cycle time (h) | First-pass audit? | Rework count | Defects found in stage | Escaped defects | Escalations |
|---|---|---|---|---|---|---|---|---|

## Definitions
- **Cycle time:** from gate `in_progress` to `approved`.
- **First-pass audit:** auditor verdict PASS on the first audit of the gate.
- **Escaped defect:** found in a later gate than the one that should have caught it.
