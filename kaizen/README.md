# kaizen/ - Continuous Improvement

Owner: `process-improvement-engineer`. Writes only here. Changes to `.claude/`, `governance/` and `profiles/` happen only through an approved change proposal.

| Path | Purpose |
|---|---|
| `metrics.md` | Gate cycle time, first-pass audit rate, rework, defects found vs escaped, escalations |
| `lessons-register.md` | Lessons with actions and status |
| `retrospectives/` | `RETRO-<date>-<scope>.md` (template `retrospective.md`) |
| `change-proposals/` | `CP-NNNN-<slug>.md` (template `change-proposal.md`); Founder approves, Chief of Staff applies |

Loop: measure -> retrospective -> proposal -> Founder decision -> apply -> measure the effect.
