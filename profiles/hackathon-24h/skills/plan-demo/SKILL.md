# Plan Demo

Delegate to `demo-defence-coach`.

## Deliverables
1. **Script (10 min):** problem and approach 2 | live demo 2 | results/validation evidence 2 | scalability and applicability 1 | Q&A 3. Per segment: what is said, what is shown, the evidence displayed.
2. **Demo path:** one happy path covering the most mandatory requirements, preloaded data, steps numbered, expected output at each step.
3. **Fallback:** recorded run clearly labelled as a recording, plus the exact words to use if the live demo fails.
4. **Evidence pack:** requirement-to-feature-to-test matrix, test results, benchmarks/metrics, screenshots, third-party disclosure list.
5. **Limits slide:** what was prioritised, what was cut, known issues - stated honestly.
